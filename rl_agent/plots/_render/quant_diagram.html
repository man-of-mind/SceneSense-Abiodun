Key idea: quantization keeps the tensor shape unchanged ([7, H, W] — same channels, same spatial grid) and only reduces the bits per value. Payload scales directly with bit-depth (16→8→4 bits ≈ 100%→½→¼), while task accuracy stays intact down to ~6 bits and degrades only mildly at 4 bits. Entropy coding (zstd) then compresses these further, losslessly.
